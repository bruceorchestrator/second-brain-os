## 2026-10-23 - Drafted posts before the voice file had real samples
**Wrong:** Wrote five X drafts from the owner's description of how they write.
**Correct:** Fill agents/twitter/_config/voice.md with 5-10 of the owner's own posts first, then draft.
**Why:** All five drafts came back rewritten. A description of a voice is not a voice.
**Trigger:** Before any agent writes in the owner's name: check that its voice file holds real samples.

# memory/outputs/

Deliverables that belong to no agent: a one-off research report, a plan, a review. One folder
per type, dated file names: `outputs/research/2026-10-24_newsletter-tools.md`.

- A recurring job's results do not go here: they live in `agents/<name>/stages/*/output/`.
- A deliverable is a file here plus a link in chat, not a wall of text in the conversation.
- When a report changes a priority, a status or a number that STATE.md tracks, update
  STATE.md in the same session. The Stop tripwire reminds you once per session when a
  report was written here and STATE.md was not touched.
